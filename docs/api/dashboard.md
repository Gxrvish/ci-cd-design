# Dashboard API

Status: accepted 2026-11-06 (Gate C part 2c).

- **Callers:** the React dashboard, scripts and tests.
- **Where:** `http://cloudforge-console.localhost:8080` serves the dashboard, `/api` and `/webhooks` (ADR-0015).
- **Source of truth:**
  - This page is the plan: resources, roles and the milestone each one arrives in.
  - The exact schemas are generated by FastAPI from the code, at `/api/openapi.json`. Writing them here too would be a second copy.
  - The node API is different: its contract is `contracts/v1.yaml`, because Go and Python both implement it.

## Conventions

1. **Bodies:** JSON in and out. Errors are `{"detail": "..."}`; 422 means the body failed validation, and its `detail` is a list. Same as the node API.
2. **Auth:** the session cookie or an API token (ADR-0015).
   - 401: not logged in, or the token expired.
   - 403: the role is too low, or the CSRF check failed.
3. **Tenancy:**
   - Every query that loads a tenant row joins `organization_member` for the caller.
   - A row outside the caller's organizations answers 404, never 403, so its existence doesn't leak.
   - The M4 tenant isolation suite calls every endpoint as a member of another organization.
4. **Lists:** a JSON array, newest first. `?limit=` defaults to 50, at most 100. Next page: `?before=<last id>`.
5. **Write-only values:**
   - Variable values never appear in a response (ADR-0007).
   - Tokens and credentials appear once, when they are created.

## Roles

| Minimum role | May |
|---|---|
| viewer | read builds, logs, steps, deployments, environments and variable names |
| developer | trigger, cancel and rebuild builds; redeploy or roll back staging and preview environments |
| admin | the same for production; variables; project settings; runners and runner tokens; fork PR approval (ADR-0013) |
| owner | members and their roles |
| platform admin (`app_user.is_platform_admin`) | node registration tokens |

## Endpoints, by milestone

Before M4 there is no login (a stub, ADR-0015). A seeded organization, `default`, owns everything.

| M | Method and path | Role | Notes |
|---|---|---|---|
| M1 | `GET /healthz` | none | 200 when the database answers |
| M1 | `POST /api/orgs/{org}/repositories` | admin | connect a repository: a public Gitea one in M1; GitHub in M3, after checking access to the installation |
| M1 | `POST /api/orgs/{org}/projects` | admin | also creates the production branch and environment |
| M1 | `POST /api/projects/{slug}/builds` | developer | manual build of an exact SHA; the branch defaults to production |
| M1 | `GET /api/builds/{id}` | viewer | steps per attempt; an archived attempt's log has a short-lived download URL |
| M2 | `POST /api/builds/{id}/cancel`, `.../rebuild` | developer | J11 or the cancel flag; a rebuild is a new build |
| M3 | `POST /webhooks/github`, `POST /webhooks/gitea/{repository_id}` | signature | rules in ADR-0004: 202, also for duplicates; 401 for a bad signature |
| M4 | `POST /api/users`, `POST /api/session`, `DELETE /api/session` | none | register, log in, log out |
| M4 | `GET /api/me`; `GET`, `POST`, `DELETE /api/me/tokens[/{id}]` | self | memberships; API tokens |
| M4 | `GET`, `POST /api/orgs`; `GET`, `POST`, `PATCH`, `DELETE /api/orgs/{org}/members[/{user_id}]` | owner to change | an organization keeps at least one owner |
| M4 | `GET /api/orgs/{org}/projects`; `GET`, `PATCH /api/projects/{slug}` | viewer, admin | `PATCH` covers staging branches, timeout, image size limit |
| M4 | `GET /api/projects/{slug}/builds` | viewer | build list |
| M4 | `GET /api/builds/{id}/attempts/{n}/log` | viewer | SSE (ADR-0006, rules 5 to 7) |
| M4 | `GET /api/projects/{slug}/variables`; `PUT`, `DELETE .../variables/{scope}/{name}` | viewer, admin | names, scopes and phases only; `PUT` takes `{value, phase}` |
| M4 | `GET /api/orgs/{org}/runners`; `POST /api/orgs/{org}/runner-tokens`; `POST /api/runners/{id}/pause`, `resume`, `revoke` | viewer, admin | a runner token names its pool (ADR-0009) |
| M4 | `POST /api/node-tokens` | platform admin | one-time agent registration token |
| M6 | `GET /api/projects/{slug}/environments`; `GET /api/environments/{id}/deployments`; `GET /api/deployments/{id}` | viewer | |
| M6 | `POST /api/environments/{id}/deployments` | developer or admin | body `{build_id}`. The live build again is a redeploy; an older one is a rollback (D1) |
| M7 | `POST /api/pull-requests/{id}/approve` | admin | body `{sha}`, compared and set against the head SHA (ADR-0013) |
| M8 | `GET`, `POST`, `DELETE /api/environments/{id}/domains[/{id}]` | viewer, admin | custom domains with TXT verification (ADR-0010) |

`POST` answers 201 with the new row, `DELETE` answers 204, and actions such as `cancel` answer 202.
